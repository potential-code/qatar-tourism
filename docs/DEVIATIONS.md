at handover.

## Frontend-only mockup

The demo has no backend. These follow from that choice.

| #   | Area                       | What it means                                                                                                                                                                         |
| --- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 9   | No backend                 | No API, database or mail server. Browser services (`client/src/services`) run the business rules over seeded data saved in IndexedDB. Hosting serves static files only                |
| 10  | Permissions in the browser | Brief §11 rules are enforced in the browser services and route guards, not on a server. They behave the same in the demo, but anyone with developer tools can change their own copy   |
| 11  | State per browser          | Each browser has its own copy of the data. Learner, trainer and admin views connect within one browser: switch with the demo toolbar or sign out and in. Two people never share state |
| 12  | Certificate verification   | The public verification page finds seeded certificates and those issued in the same browser. A certificate issued in another browser is not found                                     |
| 13  | Unsubmitted uploads        | A file chosen for an assignment but not yet submitted is lost on reload. Submitted files are kept in the browser                                                                      |
| 14  | Seeded files               | Seeded file submissions are metadata only (name, size, type). No file is stored for them                                                                                              |
| 15  | Emails and password reset  | Every email, including the password-reset link, is simulated on screen and in the notification log. Nothing is sent                                                                   |

## Known gaps

| Gap                                                            | Detail                                                                                                                                                                                                                                                                                                                 |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Speech-to-text browser support                                 | Voice practice uses the browser's Web Speech API. Use Chrome for the demo. In browsers without the API, such as Firefox, the learner records and then types what they said; the screen explains this                                                                                                                   |
| Reschedule cannot change format                                | The reschedule action changes date, time, venue and meeting reference, not in-person versus online. Editing a session can change its format only while nobody is booked or waitlisted; after that the trainer must cancel and create a new session. Brief §10 expects format changes to be highlighted in a reschedule |
| Enrolment mode is read-only                                    | Programme management shows each programme's enrolment mode (A explicit with demo approval, B open registration, C illustrative) but does not let the admin change it                                                                                                                                                   |
| Permission matrix is display-only                              | Roles and permissions shows the §11 matrix as enforced. The matrix is fixed for the trial. Role changes and trainer programme approvals are made in User and Trainer management                                                                                                                                        |
| SCORM iframe sandbox                                           | The SCORM player iframe uses `sandbox="allow-scripts allow-same-origin"` so the package can reach the SCORM API. Together these allow same-origin script access, so the isolation is weaker than a separate origin. Acceptable for our own package; host third-party packages on a separate origin                     |
| Program B post-assessment opens before short-response approval | The B post-assessment unlocks after the core lessons and one practice conversation. It does not wait for the trainer to approve the C05 short response. Completion still requires the approval                                                                                                                         |
| Excel export                                                   | Reports export CSV (UTF-8, opens in Excel). There is no native `.xlsx` export. The UI says CSV                                                                                                                                                                                                                         |
| Learner export                                                 | There is no learner-facing download of own results. Learners see them on Progress                                                                                                                                                                                                                                      |
